FAQ

What is TOML?

TOML (Tom's Obvious, Minimal Language) is a configuration file format that's easy to read due to its clear semantics. It's used by Cargo (Rust), Poetry (Python), and many other tools.

Is my data secure?

Yes! All processing happens entirely in your browser. Your configuration files are never sent to any server.

What TOML versions are supported?

We support TOML 1.0.0 specification including all features: inline tables, arrays of tables, multi-line strings, and more.
